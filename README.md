# Oltre — Bar Restaurante Valencia

Carta digitale (menu online) di **Oltre**, bar ristorante a Valencia, Spagna.

## Sito pubblicato

🔗 https://oltrevalencia.github.io/oltre-bar-restaurante-valencia/

## Cosa contiene questo repository

- `index.html` — l'unico file che genera il sito pubblicato. È l'unico file che serve modificare per aggiornare il menu, i prezzi o le informazioni del locale.

## Come aggiornare il menu

1. Modifica il file `index.html` (direttamente su github.com con "Edit this file", oppure in locale con GitHub Desktop).
2. Salva le modifiche con un breve commento che descriva cosa hai cambiato (es. "aggiunto piatto nuovo", "aggiornati prezzi estate").
3. Il sito pubblicato si aggiorna automaticamente in pochi secondi, nessun altro passaggio necessario.
